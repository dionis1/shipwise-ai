An authorized Authentication API v2 and OOH Location Finder by Address (single) specification has not been supplied.

No GLS network call, authenticated test, provider approval or production readiness is claimed. Catalog shipping remains disabled and unconfigured.

To continue, provide the local path of an authorized official OpenAPI/Swagger document or an authenticated portal session containing these contracts. Credentials should be installed through ignored runtime configuration or managed secrets, never pasted into chat or source. Provider access approval and an explicitly enabled sandbox smoke test are separate requirements after implementation.

Protected Drop-off/Pick-up and parcel-order APIs remain excluded. Parcel-shop discovery does not establish rating, booking or sales authorization.
