# Frontend

Vue 3 Composition API, strict TypeScript, Vue Router, Pinia, Vite and Tailwind CSS. Feature components handle team management, access control, audit and support lookup. Public, customer and staff experiences have separate page layouts. Feedback and pagination controls are reused. Vue I18n provides complete English, German and French resources with runtime switching and English fallback. Anonymous locale is the non-sensitive `shipwise.locale` preference, then browser language; authenticated account preference takes precedence. Intl formats dates and numbers. Shared components and light design tokens are documented in `docs/design/README.md`. Translation coverage and Vue template checks run in CI.

The session store holds only the server-returned profile and permissions in memory. No credentials are stored in localStorage. Route metadata references permission IDs; the backend remains authoritative. Expired sessions are rejected by APIs even if a previously open navigation is stale. Form failures and network failures are shown explicitly.

OpenAPI-generated models are imported by the transport and feature views. The fetch transport obtains a fresh session-bound CSRF token before writes. Email tokens arrive via fragments, are read once and immediately removed from the browser URL.

Phase 2 adds public `/compare` with exact decimal-string unit conversion, translated validation, backend-priced offer cards, honest partial/no-offer states, price/service sorting and a shared detail drawer. Guest access tokens remain component-memory only. `/admin/carriers` now uses CarrierManager for availability, append-only tariff/pricing administration and aggregate diagnostics. All new copy reuses EN/DE/FR resources; the checker additionally rejects unknown static translation keys.
